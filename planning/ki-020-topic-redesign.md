# KI-020 B — `investment-advice` Denied Topic 재설계안 (설계만, 미적용)

## 1. 현재 정의 (`scripts/guardrail/create_guardrail.py`)
- name: `investment-advice`, type: DENY
- definition: "특정 종목의 매수·매도 권유"
- examples: "이 종목을 매수하세요", "지금 파세요"

## 2. 과잉 차단 사례 (`planning/metrics/query_bench/trace_summary_20261031T041847Z.csv`)
ApplyGuardrail 재현 5건 중 4건이 OUTPUT에서 이 토픽으로 차단됐다. 입력(질문)은 5건 모두 통과.

| query | topic 차단 | grounding score |
|---|---|---|
| ROE 설명해줘 | ✓ | 0.84 (통과) |
| 우선주가 뭐야? | ✓ | 0.04 |
| WACC란? | ✓ | 0.02 |
| DCF 모델이 뭐야? | ✓ | 0.10 |
| 주당순이익 설명해줘 | — | 0.13 |

- 질문이 아니라 **용어 설명 답변**이 "매수·매도 권유"로 분류된다. 어떤 표현이 걸리는지는 미확정.
- 가설: (1) KB 문서의 `해석`·`사용 시점` 필드("PER이 낮으면 저평가 가능성" 류)가 답변에 들어가 권유로 읽힘 (2) 답변에 포함된 면책 문구("투자 판단의 보조...")가 투자 맥락 신호로 작용. 재설계 전 ApplyGuardrail로 문장 단위 분해 테스트 필요.

## 3. 재설계 후보 (definition 문구, 예시 포함)
- **Candidate 1 — 지목 + 행위 지시:** "특정 종목명·종목코드를 지목하면서 '사라', '팔라', '매수하라', '매도하라', '지금이 기회' 같은 매매 행위를 지시하거나 권유하는 내용."
  - 예시: "삼성전자 지금 사세요", "005930 매도하세요", "이 종목은 지금 들어가야 합니다"
- **Candidate 2 — 액션 추천 + 설명 제외 명시:** "구체적인 투자 행위(매수·매도·보유·비중 확대)를 사용자에게 추천하는 내용. 금융 용어·지표의 정의, 계산법, 일반적인 해석 방법 설명은 해당하지 않음."
  - 예시: "지금은 비중을 늘릴 때입니다", "이 종목은 보유하세요"
- **Candidate 3 — 토픽 분리:** `investment-advice`를 (a) 종목 매매 권유 (b) 개인 맞춤 포트폴리오 지시 두 토픽으로 나누고, 각 definition에 "용어 설명 제외"를 명시. 차단 원인 추적이 쉬워지지만 토픽 수가 늘어 평가 비용이 오른다.
- 공통: Denied Topic definition은 '무엇을 막는가'를 서술하고, 제외 범위는 명시적으로 적는다. examples에는 실제 원칙 위반 문장만 넣는다.
