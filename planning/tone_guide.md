# Haru 말투 가이드 (Phase F1 → F1.5 레이어 분리)

F1에서 AI 환각 방지용 엄격 규칙(L1)을 안내·빈 상태·에러까지 적용해 서비스가 로봇 콘솔처럼 읽혔다.
F1.5에서 문구를 세 레이어로 나누고, 레이어마다 다른 검사를 쓴다.

## 레이어 정의

| 레이어 | 대상 | 톤 | 코드 검사 |
|---|---|---|---|
| **L1 엄격** | AI 생성 텍스트: 체크리스트 AI 평가 reasoning, Bedrock KB 답변, KB 답변 자리에 뜨는 fallback(`SAFE_REPLACEMENT`·`NO_EVIDENCE_STOCK_ANSWER`) | 명사형·단문. 환각·사족 방지 | `has_tone_violation_l1` (AI reasoning 검증, 위반 시 판단 보류) |
| **L2 서비스** | 사용자 안내·빈 상태·에러·홈 히어로·사용법·placeholder·로딩(1초 이상)·CTA 설명·메시지 템플릿·API error detail | 자연스러운 평서문·제안형 (~요, ~세요, ~해 보세요) | `has_tone_violation_l2` (today message·fallback 템플릿 테스트) |
| **L3 액션** | 버튼·탭 라벨·상태 라벨·배지 | 명사 또는 짧은 동사, 조사 최소 | L1 규칙으로 검사 (CTA 라벨 테스트) |

공통 whitelist(검사 전 제거): `DISCLAIMER`(원칙 5 고정 문구), `AI_EVAL_NOTICE`, `SAFE_REPLACEMENT`.

## L1 금지 (`find_tone_violations_l1`)
| 종류 | 패턴 | 단위 |
|---|---|---|
| ending | `(해요\|에요\|예요\|이야\|어요\|아요\|여요\|워요\|네요\|군요\|죠\|세요\|까요\|게요\|래요\|대요\|보여요\|니다\|바랍니다)$` | 문장 |
| passive | `되지\s*않았\|처리되었\|확인되었\|판단되지` | 전체 |
| vague | `아직\|조금\|곧\|거의\|다소\|대략\|약간` | 전체 |
| address | `당신\|여러분\|사용자님` | 전체 |
| over_polite | `주세요\|바랍니다` | 전체 |

- 수치는 단위 포함, "약"·"대략" 대신 정확한 값 또는 "데이터 없음"
- "필요"·"개요"처럼 '요'로 끝나는 명사는 오탐하지 않도록 어미를 나열했다.

## L2 금지 (`find_tone_violations_l2`)
| 종류 | 패턴 | 비고 |
|---|---|---|
| over_polite | `바랍니다\|주시면\s*감사` | "~해 주세요"는 허용 |
| passive | `되지\s*않았\|처리되었\|확인되었\|판단되지` | |
| vague | `아직\|조금\|곧\|거의\|다소\|대략\|약간` | "잠시 후 다시 시도해 보세요"는 행동 안내라 허용 |
| address | `당신\|여러분\|사용자님` | |
| self_reference | `저희\s*Haru\|Haru는\s+` | "Haru가 정리해 드려요" 1회는 허용 |
| exclamation | `(^\|공백·따옴표)(자\|오\|좋아요)!` | "투자!" 같은 단어 안 '자!'는 오탐하지 않음 |

허용: ~요, ~세요, ~해 보세요, ~어요/아요, 짧은 설명문.

## L3 가이드
- 명사 또는 짧은 동사: "검색", "저널", "체크리스트 이어서", "판정 적용", "판단 보류", "충족"
- 조사 최소화, 마침표 없음
- 공간이 좁은 배지는 숫자 압축 허용: "체크리스트 1/3 충족"

## 적용 범위 매핑

| 범위 | 레이어 | 예시 |
|---|---|---|
| AI 평가 reasoning | L1 | "DART 2026년 반기보고서 기준 부채비율 31.1%. 200% 미만 충족." |
| Bedrock KB 답변 (프롬프트 `TONE_RULES`) | L1 | "PER: 주가 ÷ 주당순이익. 이익 대비 주가 수준을 보는 지표." |
| KB fallback 상수 | L1 | "확인된 자료 없음. DART 공시 데이터 미색인 가능성." |
| AI 평가 fallback 템플릿 | L3 접두 + L2 | "판단 보류. 평가에 쓸 재무 데이터가 부족해요." |
| 오늘의 흐름 message | L2 | "최근 결정: 삼성전자 관망 (본인 기록). 체크리스트 3개 중 0개 충족, 3개는 판단 보류 상태예요." |
| API error detail | L2 (작성 가이드, 코드 검사 없음) | "체크리스트를 찾을 수 없어요." |
| 빈 상태·삭제 확인·placeholder | L2 | "작성한 메모가 없어요. \"블록 추가\"로 첫 메모를 남겨 보세요." |
| 홈 히어로·사용법·기능 카드 설명 | L2 | "흩어진 뉴스와 시세를 Haru가 정리해 드려요. 판단은 본인의 몫이에요." |
| 버튼·탭·상태 라벨·배지 | L3 | "검색", "판정 적용", "판단 보류", "AI 평가 (Bedrock)" |
| 결정 라벨 | L3 (narrative 보존) | "매수 결정 (본인 기록)" |

## 전후 예시 10개 (F1 → F1.5)
| # | 위치 | F1 (L1 과적용) | F1.5 |
|---|---|---|---|
| 1 | 오늘의 흐름 (빈 상태) | 체크리스트 시작. 종목 검색부터. | 체크리스트를 시작할 종목을 검색해 보세요. |
| 2 | 오늘의 흐름 (미완료) | 체크리스트 0/3 충족, 3건 판단 보류. | 체크리스트 3개 중 0개 충족, 3개는 판단 보류 상태예요. |
| 3 | 오늘의 흐름 (회고) | 회고 필요. 저널에서 결정 재검토. | 저널에서 이 결정의 회고를 이어가세요. |
| 4 | AI 평가 fallback | 판단 보류. 응답 차단 (Guardrail) 또는 응답 잘림. | 판단 보류. Guardrail에 걸렸거나 응답이 중단됐어요. |
| 5 | API 에러 (404) | 체크리스트 없음. | 체크리스트를 찾을 수 없어요. |
| 6 | API 에러 (422) | 국내 상장 종목 아님. AI 평가는 6자리 종목 코드만 지원. | 국내 상장 종목만 AI 평가를 지원해요. 6자리 종목 코드를 사용해 주세요. |
| 7 | 워크북 빈 상태 | 메모 없음. "블록 추가"로 첫 메모 작성. | 작성한 메모가 없어요. "블록 추가"로 첫 메모를 남겨 보세요. |
| 8 | 삭제 확인 | 기록 삭제? 복구 불가. | 이 기록을 삭제할까요? 되돌릴 수 없어요. |
| 9 | 검색 결과 없음 | 결과 없음 | 검색 결과가 없어요 |
| 10 | 홈 히어로 | 흩어진 뉴스·시세 정리. AI 조사 · 판단 본인. | 흩어진 뉴스와 시세를 Haru가 정리해 드려요. 판단은 본인의 몫이에요. |

변하지 않은 것 (L1·L3 유지): AI 평가 reasoning 검증, `TONE_RULES` 프롬프트, 상태 라벨 "판단 보류", 버튼 "판정 적용", 면책 3종.
